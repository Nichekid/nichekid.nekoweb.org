### How to Run a Local Copy:

- Type in your terminal: <code>git clone https://github.com/Nichekid/nichekid.nekoweb.org</code>
- download [11ty](https://www.11ty.dev) ([node.js](https://nodejs.org/en/download/) required)
- Then type in your terminal: <code>npm start</code> or <code>npx @11ty/eleventy --serve</code>
- Your local copy will be visible at: [http://localhost:8080/](http://localhost:8080/)
