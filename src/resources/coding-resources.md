## Git resources:
### What’s git? 
 A version control software system, that allows you to store and manage mutiple versions of source code, software, data and much more. You can make seperate branches of the same project, and work on new features without editing the main branch!
### Is it like GitHub? 
Git is not GitHub. GitHub is usually confused as Git and the other way around, but GitHub does use git to store software, data and their versions online in a repository or repo! For an example of a repo, check out this sites repo! 

[Click here!](https://github.com/Nichekid/nichekid.nekoweb.org/tree/main)
### What's Open Source?
Usually, when something is open source, it means the source code of something is publicly avaliable to modify, study it, and then redistribute it again. Most public repos are basically open source and allow you to look at the code, edit and distribute it.

Static sites are site in which they dont need any server-side code to display info, all they need are just the raw html files to display pages, making them simpler, easier for small sites and actually more secure than dynamic sites since it renders stuff that is already made verse's having to generate it!
